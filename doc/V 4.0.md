# CupVerse Additional UX/UI Enhancements & Functional Requirements (Revision)

## Home Page Improvements

### Countdown Card Optimization

#### Issues

Current countdown timer exceeds card boundaries on larger displays and some responsive breakpoints.

#### Requirements

* Countdown timer must always remain inside card boundaries.
* Digits must automatically scale based on available card width.
* Use fluid typography (`clamp()` strategy).
* No overflow at any viewport size.
* No horizontal scrolling.
* Maintain equal spacing between countdown units.

#### Display Changes

Remove:

* "Days Left"
* Any textual duplication of remaining days

Display only:

```
12 : 08 : 24 : 16
```

With labels:

```
Days   Hours   Min   Sec
```

---

### Failure Handling

If provider fails:

#### Display

```

```

#### Fallback

* Last cached data
* Timestamp of latest successful update

### Performance Requirements

* No UI freeze during updates.
* Background sync only.
* Incremental rendering.
* Automatic retry with exponential backoff.
* Offline-first behavior maintained.
